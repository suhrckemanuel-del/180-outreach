## What was built

`tools/sources/` (plain HTTP, zero LLM tokens; downloads cached in `tenants/<t>/state/sources/`):

- `_common.py`: fetch with cache, domain de-dup against targets, pipeline and suppression, sort order.
- `aedes.py`: Aedes member map feed, Rotterdam region. 26 rows.
- `social_enterprise_nl.py`: public WordPress API + one member page each (1.5 s apart). 462 rows.
- `anbi.py`: Belastingdienst ANBI open data (CC0), Delft + Rotterdam, filters in code. 1,308 rows.
- `rotterdam_subsidies.py`: adds no rows; writes Rotterdam's 2024 subsidy amount into `size_hint`
  of 225 matching Rotterdam rows (the only size and funding signal we have).
- `mark.py`: set a candidate's status by domain (`--status rejected --why ...`), and `--pick` to
  print the next batch by the rule.

Run order matters (first source to claim a domain sets the segment): aedes, social_enterprise_nl,
anbi, rotterdam_subsidies. Re-running is safe (cached, de-duplicated, subsidy tags reset first).

**Batch rule** (in `mark.py --pick`): Delft and Rotterdam only, `status: new`, file order: a Rotterdam
subsidy of EUR 50k-1M first, then unknown size, then larger; nonprofits alternate cultural and
social. Batch 1 = `--pick nonprofit=13 social_enterprise=12 woningcorporatie=3`.
